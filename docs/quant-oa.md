# Timed quant OA simulator

Choose 1–20 questions each in arithmetic, probability and reasoning (at most 50 total), plus a 1–90 minute overall deadline. Questions use fresh seeded parameters across products/division, square differences, urns, diagnostic Bayes, maximum dice, collision/inversion indicators and uniform minima. This is a focused practice simulator, not a replica of any employer's assessment.

Use decimals or fractions. Navigation saves the current answer, optional reasoning and review flag. Save answer commits without moving. Unsaved drafts survive reload in the same tab, but only server-saved answers count at expiration. The absolute deadline is stored on the server; refresh cannot extend it. Concurrent stale revisions are rejected. Browser clock display uses the server's reported time offset.

Finish and reveal solutions ends the exam immediately. Expiration also locks answers and exposes references, derivations and section-level correct/answered totals. Active responses omit expected answers, explanations and the future random seed. Finished exams can be staged in a tutor session to examine reasoning. These local practice endpoints do not attempt to provide adversarial anti-cheating guarantees.
