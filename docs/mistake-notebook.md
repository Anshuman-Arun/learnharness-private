# Mistake notebook and targeted retries

The notebook lists eligible completed attempts: incorrect or slow arithmetic (choose the slow threshold), incorrect/unanswered completed OA questions, poor or overconfident exact-reference estimates, and stopping decisions with positive local regret. Capture copies the original source identity, question, answer and recorded reasoning. Repeated capture is deduplicated. Fermi assumptions are not treated as numeric mistakes.

Choose an error category and write what you will notice or do differently. Categories are learner-assigned; the app does not infer a diagnosis from an incorrect number. Manual numeric-reference problems are supported, with the reference explicitly labelled learner-provided.

Retry the original problem or request a new parameter set testing the same mathematical family. Fixed arithmetic ranges can have no distinct variant; the app explains when an original retry is needed. Manual problems have original retries only. Estimates use a 1% absolute-reference tolerance; other numeric retries use the question's stored absolute tolerance. Commit a new answer and explanation before references appear. Retry outcomes remain saved for comparison.

A correction is marked demonstrated only after a successful retry started after its latest saved correction. Editing a correction clears that status. One successful attempt is evidence about that problem, not durable mastery or a knowledge-graph score. The original attempt is retained separately from the correction and retry history.
